# Geography and confidence
Study rectangle (WGS84): south 17.355, west 78.468, north 17.367, east 78.481. This is a project study boundary, not a municipal or administrative district. Origin 17.3616 N, 78.4747 E is an engineering anchor near Charminar, not a surveyed landmark center.

Source: official OSM map API https://www.openstreetmap.org/api/0.6/map?bbox=78.468,17.355,78.481,17.367 retrieved 2026-11-22. Full ways crossing the requested rectangle can extend outside it; therefore generated registry covers 76 tiles rather than only the study rectangle. Raw XML preserves source versions and metadata. Derived JSON retains node IDs, coordinates and tags; SHA256 in registry identifies that JSON. No imagery scraped or proprietary map geometry traced.

Conversion: WGS84 ellipsoid lat/lon at assumed ellipsoid height zero -> ECEF -> east/north tangent plane at origin; Godot X=east, Z=-north, Y=up. Units metres. This discards elevation and is appropriate only to this small prototype. Earth curvature vertical component is deliberately discarded. No claimed survey accuracy; axis/scale sanity tests and a separate PROJ topocentric comparison validate the mathematical implementation. Four reference points differed by at most 7.67e-11 m horizontally; this is not independent field/geodetic control. Before metropolitan expansion select a stable projected/geocentric frame, measure distortion, and adopt origin rebasing.

Confidence: OSM geometry is community reference, not field verified. Named Charminar way 238186115 anchors the original landmark model. Its 48.7 m model-height parameter follows a documented reference choice, with a conflicting published height recorded in SPRINT15_REPORT.md; it is not a surveyed measurement. Other buildings retain assumed 7 m heights. Roads use numeric OSM widths when present (clamped 1–30 m), otherwise class defaults: primary 10 m, secondary 8 m, tertiary 7 m, residential 6 m, pedestrian 8 m, footway 3 m, path/steps 2 m, service 4 m, other 5 m. Illustrative sidewalks are 1 m wide. Exact footprints are retained where polygon triangulation succeeds. Relation/multipolygon buildings, roof structures, bridges, tunnels, steps and road elevation are not modeled. Shared source node IDs preserve connectivity in the dataset; there is no routing or traffic graph yet. Visual intersections alone must not be treated as traversable graph edges.

Tile rule: 256 m floor-divided indices, including negative coordinates. Feature AABB registers overlap tiles. Runtime reference counting renders a whole feature once while any loaded tile refers to it. Up to 3x3 registry tiles are loaded. This is synchronous creation, not frame-budgeted streaming; large boundary features and mesh/collider creation can cause stalls. Ground spans 2.2 km. Study-boundary and fall recovery now return the player to spawn and reset velocity; this is regression-tested on the host, not verified on a phone.

Accuracy gate before accepting authentic: compare landmark center and junction topology to independently licensed references and field observations; record reference date, source IDs, residuals and uncertainty. Proposed tolerances are 2 m transform residual against a trusted GIS calculation and 5 m landmark placement against an independently validated reference; these are targets, not achieved results. Never shift source roads for aesthetics silently.
