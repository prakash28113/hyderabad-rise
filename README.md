# Hyderabad: Rise of an Empire

Geographically anchored, offline-first Godot Android prototype of the Charminar area.

The development source is being imported with its original Git history into `dev/sprint1-geographic-foundation`. Temporary recovery branches support this approved one-time import. No game changes are merged into main and no release is published.

The v0.1.6 APK and source package have been built and verified locally. Physical Android performance and full visual-authenticity acceptance remain open. See the development branch QA report for actual measurements and licensing.
